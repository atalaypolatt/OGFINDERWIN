# OGFINDERWIN

Pair Arama - Windows sürümü. Pump.fun ve Stonk.fun token arama arayüzü.

## Kurulum
1. [Node.js LTS](https://nodejs.org) ve Google Chrome kurun.
2. Depoyu ZIP olarak indirip çıkarın.
3. `Pair Arama.vbs` dosyasına çift tıklayın.
4. Alternatif: terminalde `node server.js` çalıştırıp `http://127.0.0.1:4317` adresine gidin.
5. Benzer fotoğraf analizi için `npm install` çalıştırın.

Sunucu yalnızca yerel bilgisayarda dinler. Hatalar için `server.err.log` dosyasını inceleyin.
